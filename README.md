# Guideline on How To Write a REAME.md file on Gith 
## Overview 
- Create a directory. 
```bash  
mkdir <name of dir>  
cd <name of dir>  
```  
---  
- Intialise the directory  
```bash  
git init  
```  
---    
- Create a file  
```bash  
touch README.md  
```  
---      
- Add content to the file  
```bash  
```  
---    
- Check if files are tracked or untracked    
```bash  
git status  
```  
---      
- Add to staging area  
```bash  
git add .  
```  
---    
- Commit the files  
```bash  
git commit -m "intial commit"  
```  
---      
- Create a new repo in github to receive your work  
```bash  
Go to your github.com/new and create repository  
```  
---    
- git remote  
```bash  
git remote add origin <url of the repo>  
```  
---    
- Create a new branch for main  
```bash  
git branch -M main  
```  
---    
- push to github  
```bash  
git push -u origin main  
```
